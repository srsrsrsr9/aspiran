# Data interpretation

Schema: `upsc-pods/data-interpretation@1` · Folder: `content/data-interpretation/` · Family: Practise · Engine: choose

**Exam:** prelims · papers: prelims-csat, prelims-gs1 · formats: csat-data, pre-data

**Sound:** Tick on a pick, a santoor chime when right, a soft nudge (never a buzzer) when wrong.

**Motion:** The picked option settles in 150 ms; the explanation rises in 200 ms.

## How to fill it

A small table from the source, then two to four questions that need a calculation from it (a ratio, a difference, a percentage change, a rank).
- table: copy the numbers exactly from the source. columns: the value headers. Each row has one value per column.
- answerExpr: the arithmetic using numbers from the table, digits and + - * / ( ) only. The validator checks it equals the right option (to the rounding shown).
- options: numbers written the way the answer is rounded, e.g. "about 1.6".
