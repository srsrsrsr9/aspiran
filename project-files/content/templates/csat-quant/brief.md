## How to fill it

CSAT numeracy problems at Prelims level, solved in under two minutes each.
- Write each problem yourself, on the topics the source lists. Numbers should be friendly (no calculator needed).
- options: four numbers with units, written the same way in English and Hindi (digits stay digits). Wrong options come from common slips (adding instead of averaging, a percentage of the wrong base).
- answerExpr: the arithmetic for the right option, digits and + - * / ( ) only, e.g. "(40*3+60*2)/5". The validator checks it equals the right option.
- steps: the shortest clear working.
