# Timeline shuffle

Schema: `upsc-pods/timeline-shuffle@1` · Folder: `content/timeline-shuffle/` · Family: Play · Engine: order

**Exam:** prelims · papers: prelims-gs1 · formats: pre-order

**Sound:** Tap to pick, a wooden snap as each tile locks, a chime when the line is complete.

**Motion:** Tiles spring into slots (300 ms, slight overshoot); values count up as each locks.

## How to fill it

Put 3 to 6 events in chronological order. Years appear as each one locks in.
- items: oldest first. The app shuffles them. One event per year.
- event: 12 words or fewer. year: from the source.
- takeaway: 24 words or fewer, the thread that links the events.
- memoryHook: optional, 18 words or fewer. Only if the list is worth memorising: an acronym, a picture or a tiny story built from the items. Write the Hindi hook natively in Hindi (it may differ from the English). Use null if nothing honest fits; a hook never replaces understanding.
