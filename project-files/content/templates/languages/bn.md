# Bengali (বাংলা): style note

Status: planned. Turn it on once a Bengali editor is found. Until then this note is a starting point, and the editor writes the rest.

- Modern standard Bengali as Bengali newspapers and state-board textbooks use it, in Bengali script. Address the reader respectfully and without gender.
- Exam note: the Prelims papers are set in English and Hindi only, so on Prelims-style pieces give the English term in brackets the first time a technical term appears. Mains answers and the interview can be in Bengali, so Mains-style pieces use the Bengali term alone.
- Starter terms, which the editor should confirm against the state glossary: সংবিধান (Constitution), অনুচ্ছেদ (Article), সংশোধনী (Amendment), সংসদ (Parliament), লোকসভা, রাজ্যসভা, মৌলিক অধিকার (Fundamental Rights), মৌলিক কর্তব্য (Fundamental Duties).
- Two registers: content (facts, statements, options, questions) in standard Bengali; comments and instructions (explanations, tips, nudges, guided steps) in colloquial, spoken Bengali, the way a friendly senior talks. Still respectful and free of gender.
- Keep acronyms aspirants use as is (GDP, IMD, RBI). Numbers stay as Western digits.
