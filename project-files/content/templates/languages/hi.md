# Hindi (हिन्दी): style note

Status: launch language. Hindi is written inside each pack by the content writer, not through a translation file. This note is the same guidance the writer's system prompt carries.

- Natural Hindi as aspirants read it, in Devanagari. Standard terms: अनुच्छेद (Article), संशोधन (Amendment), धन विधेयक (Money Bill), संयुक्त बैठक (joint sitting), राष्ट्रपति की अनुमति (assent), मौलिक अधिकार (Fundamental Rights), मौलिक कर्तव्य (Fundamental Duties), लोकसभा, राज्यसभा, मानसून.
- Keep acronyms aspirants use as is (IMD, LPA, GDP, UNESCO).
- Two registers: content in standard Hindi; comments and instructions (the "why", tips, nudges, guided steps, questions to the reader) in colloquial, spoken Hindi, with the everyday English words aspirants use. Still आप, and free of gender.
- Numbers stay as digits. Hindi may run up to about a third longer than the English.
- "Editor's source notes" is "संपादक के स्रोत नोट्स".
- Exam note: Prelims papers are set in English and Hindi, so Hindi terms should match the ones in the official Hindi paper.
