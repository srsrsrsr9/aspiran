# Marathi (मराठी): style note

Status: planned. Turn it on once a Marathi editor is found. Until then this note is a starting point, and the editor writes the rest.

- Modern standard Marathi as Marathi newspapers and state-board textbooks use it, in Devanagari script. Address the reader respectfully and without gender.
- Exam note: the Prelims papers are set in English and Hindi only, so on Prelims-style pieces give the English term in brackets the first time a technical term appears. Mains answers and the interview can be in Marathi, so Mains-style pieces use the Marathi term alone.
- Starter terms, which the editor should confirm against the state glossary: राज्यघटना (Constitution), कलम (Article), घटनादुरुस्ती (Amendment), संसद (Parliament), लोकसभा, राज्यसभा, मूलभूत हक्क (Fundamental Rights), मूलभूत कर्तव्ये (Fundamental Duties).
- Two registers: content (facts, statements, options, questions) in standard Marathi; comments and instructions (explanations, tips, nudges, guided steps) in colloquial, spoken Marathi, the way a friendly senior talks. Still respectful and free of gender.
- Keep acronyms aspirants use as is (GDP, IMD, RBI). Numbers stay as Western digits.
