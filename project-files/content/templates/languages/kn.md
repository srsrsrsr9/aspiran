# Kannada (ಕನ್ನಡ): style note

Status: planned. Turn it on once a Kannada editor is found. Until then this note is a starting point, and the editor writes the rest.

- Modern standard Kannada as Kannada newspapers and state-board textbooks use it, in Kannada script. Address the reader respectfully and without gender.
- Exam note: the Prelims papers are set in English and Hindi only, so on Prelims-style pieces give the English term in brackets the first time a technical term appears. Mains answers and the interview can be in Kannada, so Mains-style pieces use the Kannada term alone.
- Starter terms, which the editor should confirm against the state glossary: ಸಂವಿಧಾನ (Constitution), ವಿಧಿ (Article), ತಿದ್ದುಪಡಿ (Amendment), ಸಂಸತ್ತು (Parliament), ಲೋಕಸಭೆ, ರಾಜ್ಯಸಭೆ, ಮೂಲಭೂತ ಹಕ್ಕುಗಳು (Fundamental Rights), ಮೂಲಭೂತ ಕರ್ತವ್ಯಗಳು (Fundamental Duties).
- Two registers: content (facts, statements, options, questions) in standard Kannada; comments and instructions (explanations, tips, nudges, guided steps) in colloquial, spoken Kannada, the way a friendly senior talks. Still respectful and free of gender.
- Keep acronyms aspirants use as is (GDP, IMD, RBI). Numbers stay as Western digits.
