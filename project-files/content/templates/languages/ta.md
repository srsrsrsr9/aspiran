# Tamil (தமிழ்): style note

Status: planned. Turn it on once a Tamil editor is found. Until then this note is a starting point, and the editor writes the rest.

- Modern standard Tamil as Tamil newspapers and state-board textbooks use it, in Tamil script. Address the reader respectfully and without gender.
- Exam note: the Prelims papers are set in English and Hindi only, so on Prelims-style pieces give the English term in brackets the first time a technical term appears. Mains answers and the interview can be in Tamil, so Mains-style pieces use the Tamil term alone.
- Starter terms, which the editor should confirm against the state glossary: அரசியலமைப்பு (Constitution), சட்டப்பிரிவு (Article), திருத்தம் (Amendment), நாடாளுமன்றம் (Parliament), மக்களவை (Lok Sabha), மாநிலங்களவை (Rajya Sabha), அடிப்படை உரிமைகள் (Fundamental Rights), அடிப்படைக் கடமைகள் (Fundamental Duties).
- Two registers: content (facts, statements, options, questions) in standard Tamil; comments and instructions (explanations, tips, nudges, guided steps) in colloquial, spoken Tamil, the way a friendly senior talks. Still respectful and free of gender.
- Keep acronyms aspirants use as is (GDP, IMD, RBI). Numbers stay as Western digits.
