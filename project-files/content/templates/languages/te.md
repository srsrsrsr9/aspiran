# Telugu (తెలుగు): style note

Status: pilot (the third language). Packs reach Telugu through translation files made from the checked English. A Telugu editor approves each file before it is shown.

## Register

- Modern standard Telugu (వ్యావహారిక భాష) as Telugu newspapers and Telugu Akademi textbooks use it. Not the old literary register (గ్రాంథిక భాష).
- Address the reader as మీరు, and keep it free of gender (no "విద్యార్థి మిత్రులారా" style address that assumes a group).
- Short sentences. Telugu runs to fewer, longer words than English, so word limits are rarely the problem; a line that is long on screen is. Keep it as tight as the English.

## Two registers

- Content (statements, options, exam-style questions, facts, passages, titles): modern standard Telugu, as above.
- Comments and instructions (the "why" explanation, tips, nudges, guided steps, questions to the reader): colloquial spoken Telugu, the way a friendly senior talks, with the everyday English words aspirants use (exam, mock, revision, syllabus, notes). Still respectful (మీరు) and free of gender.
- Example. Content: "ప్రాథమిక విధులు రాజ్యాంగంలోని అధికరణ 51A లో ఉన్నాయి." Comment: "ఇక్కడ చాలామంది తికమకపడతారు. 42వ సవరణతోనే ఈ విధులు వచ్చాయి, మొదట్లో లేవు. ఇది గుర్తుపెట్టుకోండి."

## Exam note, which matters for terms

- The Prelims papers are set in English and Hindi only. A Telugu-medium aspirant still meets the English term in the paper, so on Prelims-style pieces (statements, pairs, lists, options) give the English term in brackets the first time a technical term appears, for example ప్రాథమిక విధులు (Fundamental Duties).
- Mains answers and the interview can be in Telugu, so Mains-style pieces (answer skeletons, case studies, essays) use the Telugu term alone.

## Starter glossary (an editor confirms each term against the Telugu Akademi glossary)

| English | Telugu |
| --- | --- |
| Constitution | రాజ్యాంగం |
| Article | అధికరణ (ప్రకరణ in some textbooks; use one consistently) |
| Amendment | సవరణ |
| Parliament | పార్లమెంటు |
| Lok Sabha, Rajya Sabha | లోక్‌సభ, రాజ్యసభ |
| Fundamental Rights | ప్రాథమిక హక్కులు |
| Fundamental Duties | ప్రాథమిక విధులు |
| Directive Principles | ఆదేశిక సూత్రాలు |
| Money Bill | ద్రవ్య బిల్లు |
| joint sitting | ఉమ్మడి సమావేశం |
| President's assent | రాష్ట్రపతి ఆమోదం |
| Supreme Court, High Court | సుప్రీంకోర్టు, హైకోర్టు |
| Election Commission | ఎన్నికల సంఘం |
| monsoon | రుతుపవనాలు |
| Emergency | అత్యవసర పరిస్థితి |

- Keep acronyms aspirants use as is (GDP, IMD, UNESCO, RBI).
- Numbers stay as Western digits, as in Telugu newspapers.

## Fixed phrases

- "Editor's source notes": ఎడిటర్ సోర్స్ నోట్స్
- Story spine openers, in order: ప్రతిరోజూ, ఒకరోజు, దాని వల్ల, చివరికి, అప్పటి నుంచి
