# Rank it

Schema: `upsc-pods/rank-it@1` · Folder: `content/rank-it/` · Family: Play · Engine: order

**Exam:** prelims · papers: prelims-gs1 · formats: pre-order, pre-data

**Sound:** Tap to pick, a wooden snap as each tile locks, a chime when the line is complete.

**Motion:** Tiles spring into slots (300 ms, slight overshoot); values count up as each locks.

## How to fill it

Rank 3 to 6 items by a number (area, length, population). Values appear as each tile locks in.
- items: in the CORRECT order, largest value first. The app shuffles them.
- value: copied exactly from the source, all in the same unit.
- takeaway: 24 words or fewer, a pattern worth remembering (not just the top item).
- memoryHook: optional, 18 words or fewer. Only if the list is worth memorising: an acronym, a picture or a tiny story built from the items. Write the Hindi hook natively in Hindi (it may differ from the English). Use null if nothing honest fits; a hook never replaces understanding.
