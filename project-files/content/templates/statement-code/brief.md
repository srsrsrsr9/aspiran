# Statements with codes

Schema: `upsc-pods/statement-code@1` · Folder: `content/statement-code/` · Family: Play · Engine: choose

**Exam:** prelims · papers: prelims-gs1 · formats: pre-statement-code, pre-select-items

**Sound:** Tick on a pick, a santoor chime when right, a soft nudge (never a buzzer) when wrong.

**Motion:** The picked option settles in 150 ms; the explanation rises in 200 ms.

## How to fill it

The classic Prelims format: numbered statements (or items), then "Which of the statements given above is/are correct?" with codes. The app builds the four coded options and the answer from truth, so you only write the statements.
- statements: 2 to 4, each clearly true or false from the source. Use the traps UPSC uses: an extreme word, a wrong number, a swapped body.
- kind "items" when the stem asks which items fit (for example, which of these are constitutional bodies).
- truth: one per statement, in order. Avoid all true or all false more than once in a pack.
- why: name each wrong statement and correct it from the source.
