Marking in UPSC Prelims General Studies Paper I, as described in recent CSE notices (to be checked against the 2027 notice): each question has four options and carries 2 marks. A wrong answer costs one-third of the marks for that question, which is 0.66. An unanswered question costs nothing.
What this means: a blind guess between four options is worth about zero marks on average. If the aspirant can confidently rule out one option, guessing between the remaining three is worth about +0.22. If they can rule out two, guessing between the remaining two is worth about +0.67.
So "rule out options first, then guess" is sound, while "never guess" and "always guess" are both poor rules. Ruling out has to be honest: if the aspirant is only half sure an option is wrong, it is not ruled out.
Sun Tzu's advice to choose one's battles fits here: put effort where the odds favour you.
