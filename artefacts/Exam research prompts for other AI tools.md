# Exam research: prompts for other AI tools (Part 1)

These prompts are for **Part 1: finding as many exam-help apps, books and methods as possible**.
Their job is to catch anything my catalogue misses. Paste each prompt as it is. Save each answer
as a text file and bring it back here. I'll merge the new items, remove duplicates, and check links.

Which tool gets which prompt:
- **Perplexity** (free): best for live web search with sources. Prompts A and B.
- **Gemini** (free, use "Deep Research" if your account has it): good at long lists. Prompt C.
- **Kimi** (free): strong on Chinese, Korean and Japanese sources that the others miss. Prompt D.
- **ChatGPT** (free): good at "what's missing from this list". Prompt E, run last.

## Prompt A: Perplexity, apps (global)

```
I am building a complete catalogue of apps and websites that help students do well in exams.
Example: https://www.retain.cards/

List at least 40 apps or websites, worldwide, that are live in 2026. Include flashcard and
spaced-repetition apps, AI tutors, question banks, mock-test sites, focus and planning apps,
note-taking apps used for study, and co-study (study-with-others) apps.

For each one give, in a table:
1. Name
2. Website link
3. Free, freemium or paid
4. What it does, in one line
5. The main learning idea it relies on (for example spaced repetition, practice tests,
   adaptive questions, Pomodoro timer, studying alongside others)
6. Your source link

Rules: only real products you can link to. Mark anything shut down or merged. Don't
include ones that only sell homework answers. Don't add commentary.
```

## Prompt B: Perplexity, India and UPSC

```
List at least 40 apps, websites, YouTube channels, Telegram communities, coaching
institutes and books that Indian students use to prepare for UPSC Civil Services,
state PSC exams, SSC, banking, JEE, NEET and CAT, as of 2026.

For each one give, in a table:
1. Name
2. Exam(s) it serves
3. Link
4. Free, freemium or paid (with rough price if shown)
5. What it does, in one line
6. The main method it relies on (for example test series, answer-writing feedback,
   previous-year question analysis, mentorship, daily current affairs, AI evaluation)
7. Source link

Include new AI-based UPSC tools launched in 2024 to 2026. Mark any that have shut down
or been bought. Don't add commentary.
```

## Prompt C: Gemini, books, courses and creators

```
Make a complete list of books, online courses, YouTube creators and research websites
about how to study, remember and do well in exams. Aim for 50 or more.

Cover:
- Books by learning scientists (for example "Make It Stick", "How We Learn",
  "Why Don't Students Like School?")
- Popular self-help study books (for example "Ultralearning", "A Mind for Numbers")
- Memory books (memory palace, memory champions)
- Online courses (for example "Learning How to Learn" on Coursera)
- YouTube study creators with large followings
- Free research websites for students and teachers (for example The Learning Scientists)
- Books by Indian exam toppers or about UPSC strategy

For each: title, author or creator, year, link, a one-line summary, the 3 to 5 central
ideas it teaches, and whether the author is a researcher, a teacher, or an influencer.
Present as a table. Only include items that really exist.
```

## Prompt D: Kimi, East Asian study culture

```
China, South Korea and Japan have very intense exam cultures (Gaokao, Suneung, Japanese
university entrance exams, civil service exams such as 公务员考试 and 공무원 시험).

List at least 30 apps, websites, study methods and books that students in these
countries use to prepare for exams, as of 2026. Include ones that are little known
outside the region. Examples of the kind of thing I mean: YPT (Yeolpumta), Zuoyebang,
Yuanfudao, Fenbi (粉笔) for civil-service exams, Studyplus in Japan, "study cafés",
wrong-answer notebooks (错题本 / 오답노트).

For each give: name (in English and the original language), country, type (app, website,
method, book, place), link if any, what it does in one line, and the main idea it relies
on. Present as a table. Mark anything that has shut down or been restricted by regulators
(for example China's 2021 tutoring rules).
```

## How to check what the tools give you

Free AI tools sometimes invent products or books. Before you trust an item:
1. Open the link. If there's no link or it doesn't load, treat the item as unconfirmed.
2. For books, search the title on Amazon.in or Goodreads to confirm the author.
3. Bring the answers back here. I'll check them again and keep only what's real.
